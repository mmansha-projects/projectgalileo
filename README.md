# Project Galileo

Arduino IDE board support package for the Galileo (i586) boards, maintained by **M.Mansha**
([LinkedIn](https://www.linkedin.com/in/mmansha)).

Install it through the Arduino IDE Boards Manager by adding this project's package index URL
under *File > Preferences > Additional Boards Manager URLs*.
